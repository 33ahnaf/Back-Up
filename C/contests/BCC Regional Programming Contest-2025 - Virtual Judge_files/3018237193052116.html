Problem Statement

Compute A×BA \times BA×B.

Constraints

  • 1≤A≤1001 \leq A \leq 1001≤A≤100
  • 1≤B≤1001 \leq B \leq 1001≤B≤100
  • All values in input are integers.

Input

Input is given from Standard Input in the following format:

AAA BBB

Output

Print the value A×BA \times BA×B as an integer.

Sample 1

Inputcopy Outputcopy 
2 5

10

We have 2×5=102 \times 5 = 102×5=10.

Sample 2

Inputcopy Outputcopy 
100 100

10000
